# 42 São Paulo

Central index for projects developed during my studies at 42 São Paulo. Each
implementation is maintained in its own repository.

## About 42

[42](https://www.42network.org/) is an international network of tuition-free
programming schools, founded in Paris in 2013. Its curriculum has no traditional
classes or lectures: students learn by completing projects, collaborating, and
evaluating each other's work.

### The Piscine

The [Piscine](https://piscina.42sp.org.br/)—French for "swimming pool"—is the
intensive admission process. At 42 São Paulo, it is a 26-day, in-person immersion
where candidates learn programming fundamentals and experience the school's
methodology without requiring previous programming experience.

### The Common Core

Candidates admitted after the Piscine enter the Common Core: the shared technical
foundation used across the 42 network. Its projects cover areas such as C, algorithms,
data structures, Unix processes, networks, system administration, object-oriented
programming, and client-server development.

### How Learning Works

- **Project-based learning:** knowledge is acquired by researching, building, testing,
  and improving working software.
- **Peer learning:** students solve problems collaboratively and exchange knowledge
  instead of relying on traditional lectures.
- **Peer evaluation:** projects are reviewed by other students, requiring each solution
  to be tested, explained, and defended.
- **Self-directed progress:** students organize their own work, learn from failed
  attempts, and advance by validating increasingly complex projects.
